## 🚀 How to Deploy on GitHub & Vercel (Step-by-Step)

1. **Unzip this Archive:** Extract `freeinvoice-store-complete.zip` on your computer.
2. **Upload to GitHub:**
   - Create a new repository on GitHub (e.g., `freeinvoice-store`).
   - Upload all extracted files (`index.html`, `image-reducer.html`, `assets/`, `vercel.json`, etc.) to the root of the repository and commit.
3. **Deploy on Vercel:**
   - Log in to [Vercel.com](https://vercel.com/) with your GitHub account.
   - Click **Add New Project** → Import your `freeinvoice-store` repository.
   - Framework Preset: **Other (Static HTML)** → Click **Deploy**.
   - Within 15 seconds your website will be live!
4. **Connect Custom Domain (`freeinvoice.store`):**
   - In Vercel Project → **Settings** → **Domains** → Add `freeinvoice.store` and `www.freeinvoice.store`.
   - Update your domain registrar's DNS records (`A` record `@` -> `76.76.21.21` and `CNAME` `www` -> `cname.vercel-dns.com`).
5. **Activate Contact Form (`gggrameez93@gmail.com`):**
   - Once the site is live, open `https://freeinvoice.store/contact.html` and send 1 test message.
   - Open your Gmail (`gggrameez93@gmail.com`) and click the **Activate Form** button from FormSubmit. After that, every visitor message will arrive straight in your Gmail inbox!
6. **Connect Your Blogger Blog Link:**
   - In the header and footer, the single **Blog ↗** button currently links to `https://freeinvoice-blog.blogspot.com`. You can replace that URL with your exact Blogger address or set up a subdomain `blog.freeinvoice.store` in Blogger settings!
